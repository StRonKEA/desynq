Araştırmadan çıkanlar

Cloudflare WARP / 1.1.1.1 Ana ekranda büyük güç anahtarı. Mod seçimi “Basic / Full” gibi sade isimler. Karmaşık ayar menüde.
Mullvad VPN Set-and-forget: yeşil/kırmızı durum, tek bakışta anlaşılır. Split tunneling ayrı ekran — liste ancak o mod açılınca.
Nord / Norton split tunnel Önce mod (tümü / sadece seçilenler), sonra liste. Liste görünürlüğü moda bağlı — tam senin istediğin kural.
GoodbyeDPI UI / zapret GUI Başlat–durdur + tray. Log ikincil. Güç kullanıcı preset’leri ayarda; günlük kullanıcıya tek düğme.

Akıllı kurallar (bunu kodlarız)

  1. Ana nesne güç anahtarı — WARP/Mullvad gibi. Açınca ölçer + uygun düzeltmeyi uygular (UAC bir kez).
  2. Mod, sekmeyi yönetir — “Tüm bilgisayar” ⇒ Siteler paneli/sekmesi yok. “Sadece siteler” ⇒ liste ana iş.
  3. İlk açılış — boş config: “Bir site yaz veya tüm bilgisayarı aç” (iki büyük kart). Eski 3 sekmeli Status değil.
  4. Log — altta ince çubuk / Ayrıntı; yarım ekran asla.
  5. Gelişmiş — DNS pin vs resolver, strateji adı, refresh → Ayarlar (dişli). Ana sayfada yok.
